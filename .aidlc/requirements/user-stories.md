# 用户故事文档 - 优惠券发放与核销中心

## 概述

本文档定义了系统的用户故事，从用户角度描述系统功能需求。共包含12个用户故事，覆盖4种角色（运营人员、普通用户、核销人员、管理员）的主要使用场景。

## 用户角色定义

| 角色标识 | 角色名称 | 描述 | 核心权限 |
|----------|----------|------|----------|
| admin | 管理员 | 全局监控和数据统计 | 统计面板、异常监控、用户管理 |
| operator | 运营人员 | 创建和管理优惠券活动 | 活动CRUD、风控标记审核 |
| customer | 普通用户 | 浏览、领取和使用优惠券 | 领券、查看我的券、使用券 |
| verifier | 核销人员 | 负责优惠券的核销 | 核销验证、核销记录查询 |

## 用户故事列表

### US-001: 创建优惠券活动
- **作为** 运营人员
- **我希望** 创建优惠券活动并设置库存和有效期
- **以便** 推出营销活动
- **优先级**: P0
- **相关需求**: FR-002
- **验收标准**: 可以成功创建活动并设置所有参数

### US-002: 编辑和暂停活动
- **作为** 运营人员
- **我希望** 编辑和暂停活动
- **以便** 灵活调整活动策略
- **优先级**: P0
- **相关需求**: FR-002
- **验收标准**: 可以修改活动参数和状态

### US-003: 浏览可领取优惠券
- **作为** 普通用户
- **我希望** 浏览可领取的优惠券
- **以便** 找到适合我的优惠
- **优先级**: P0
- **相关需求**: FR-003, FR-006
- **验收标准**: 可以看到所有可领取的优惠券列表

### US-004: 一键领取优惠券
- **作为** 普通用户
- **我希望** 一键领取优惠券
- **以便** 快速获得优惠
- **优先级**: P0
- **相关需求**: FR-003
- **验收标准**: 可以快速领取优惠券并获得券码

### US-005: 查看我的券包
- **作为** 普通用户
- **我希望** 查看我的券包和使用状态
- **以便** 知道哪些券可用
- **优先级**: P1
- **相关需求**: FR-008
- **验收标准**: 可以按状态筛选查看已领取的优惠券

### US-006: 查看AI推荐券
- **作为** 普通用户
- **我希望** 看到AI为我推荐的券
- **以便** 发现我可能需要的优惠
- **优先级**: P1
- **相关需求**: FR-006
- **验收标准**: 可以看到个性化推荐券列表和推荐理由

### US-007: 核销优惠券
- **作为** 核销人员
- **我希望** 扫描/输入券码完成核销
- **以便** 验证券的有效性
- **优先级**: P0
- **相关需求**: FR-004
- **验收标准**: 可以验证券码并完成核销操作

### US-008: 查询核销历史
- **作为** 核销人员
- **我希望** 查询核销历史
- **以便** 对账和排查问题
- **优先级**: P1
- **相关需求**: FR-009
- **验收标准**: 可以按条件查询核销记录

### US-009: 查看实时统计
- **作为** 管理员
- **我希望** 查看实时统计面板
- **以便** 监控活动效果
- **优先级**: P0
- **相关需求**: FR-005
- **验收标准**: 可以看到系统级统计数据可视化图表

### US-010: 查看风控告警
- **作为** 管理员
- **我希望** 查看异常和风控告警
- **以便** 及时处理风险
- **优先级**: P1
- **相关需求**: FR-007, FR-010
- **验收标准**: 可以看到风控拦截记录和告警信息

### US-011: 审核风控拦截
- **作为** 运营人员
- **我希望** 审核风控拦截的领券
- **以便** 对边界case做人工判断
- **优先级**: P1
- **相关需求**: FR-010
- **验收标准**: 可以审核风控记录并做出放行/拒绝决定

### US-012: 角色登录
- **作为** 所有角色
- **我希望** 使用对应角色账号登录
- **以便** 使用对应功能
- **优先级**: P0
- **相关需求**: FR-001
- **验收标准**: 不同角色登录后看到不同的功能界面

## 用户故事验收标准细化

### US-001验收标准
1. 可以输入活动名称、面额、库存、有效期等参数
2. 参数校验正确（库存>0，结束时间>开始时间等）
3. 活动创建成功后状态为草稿
4. 可以查看创建的活动详情

### US-003验收标准
1. 未登录用户重定向到登录页
2. 登录后看到当前可领取的优惠券列表
3. 列表显示券面额、有效期、剩余库存等信息
4. 可以按条件筛选活动

### US-004验收标准
1. 点击领取按钮后触发领券流程
2. 库存扣减正确，不会超发
3. 成功领取后显示券码和详情
4. 重复领取提示"已领取"
5. 库存不足提示"已抢光"

### US-007验收标准
1. 输入券码后验证券的有效性
2. 有效券可以成功核销
3. 过期券提示"券已过期"
4. 已核销券提示"已核销"（幂等）
5. 生成核销记录

### US-009验收标准
1. 显示系统总活动数、领取数、核销数、核销率
2. 可以按时间范围筛选统计数据
3. 数据可视化图表清晰易懂
4. 数据与数据库实际数据一致

## 用户旅程

### 运营人员旅程
1. 登录系统 → 2. 创建活动 → 3. 发布活动 → 4. 监控活动数据 → 5. 审核风控记录

### 普通用户旅程
1. 登录系统 → 2. 浏览可领取券 → 3. 查看AI推荐 → 4. 领取优惠券 → 5. 查看我的券包

### 核销人员旅程
1. 登录系统 → 2. 输入券码核销 → 3. 查看核销记录 → 4. 查询历史记录

### 管理员旅程
1. 登录系统 → 2. 查看统计面板 → 3. 监控风控告警 → 4. 查看系统状态

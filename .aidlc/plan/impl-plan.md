## 3. 实现范围与原则

- 单机前后端分离，固定目录 `src/backend|frontend|shared`。
- 后端 Express + Prisma + PostgreSQL 16；前端 React + Vite。
- Bedrock SDK/API Key 双路径；推荐降级热门规则，风控降级 `risk_rules`。
- 先建立迁移、认证和审计基础，再实现业务后端；前端基座完成后按角色页面并行；最后执行真实端到端和非功能验证。

- 2026-07-30 范围变更：新增 customer/operator/verifier 自助注册（FR-011/US-013），实现于 `/auth/register` 与各站点 `/register`。
